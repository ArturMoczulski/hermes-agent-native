# Kilo Code setup

This project is configured for Kilo Code with the `first-builder` agent profile.

- Agent profile: `.kilo/agents/first-builder.md`
- Project instructions: `.kilo/rules/first-builder.md`
- Kilo project config: `kilo.jsonc`

In Kilo Code, select the `first-builder` agent for work in this repository. The
profile deliberately points back to the repository's canonical instructions so
that updates to the First Builder role do not require keeping a second complete
copy in sync.
